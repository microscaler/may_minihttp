# CA-07 measurement: pooled HTTP/1.1 baseline on ms02

Date: 2026-07-14
Probe: `examples/client_pool_audit.rs`
Target: `http://ms02:8090/` (`pact-mock-server`, HTTP/1.1)
Run: 8 may request coroutines, 25 requests per coroutine, four connections per origin

| Metric | Result |
|---|---:|
| requests | 200 |
| errors | 0 |
| response bytes | 8,800 |
| elapsed | 611 ms |
| p50 / p95 / p99 | 7,269 / 92,235 / 168,586 µs |
| connections created | 4 |
| connections reused | 196 |
| pool waits | 155 |
| pool wait time | 1,119,189 µs |
| connections discarded | 0 |

Command used:

```text
cargo run --quiet --example client_pool_audit --features client -- \
  http://ms02:8090/ 8 25 4
```

## Interpretation

The bounded HTTP/1.1 pool reused 98% of connections and completed the run without errors. The
tail latency and pool-wait time show that four connections are a deliberately queueing workload,
not evidence that HTTP/2 is required. This target is a pact mock server rather than a deployed
Sesame-IDAM, BRRTRouter, or Hauliage path, and it does not establish peer ALPN support. Repeat the
same matrix against representative production paths before a CA-07 go/no-go decision.
