# Story 01.5: Response — Status, Headers, Body, JSON

## Description

Implement the `Response` struct for reading and inspecting HTTP responses. Supports status code inspection, header access, body reading, JSON deserialization, and convenience methods like `is_success()` and `ensure_success()`.

## Functional Requirements

- [ ] `may_minihttp/src/client/response.rs` contains the `Response` struct
- [ ] `Response` struct fields:
  - `status: StatusCode` (from `http 0.2`)
  - `headers: HeaderMap`
  - `body: Vec<u8>` — buffered response body
- [ ] `Response::status(&self) -> StatusCode` — return the HTTP status code
- [ ] `Response::is_success(&self) -> bool` — true for 2xx status codes
- [ ] `Response::is_client_error(&self) -> bool` — true for 4xx status codes
- [ ] `Response::is_server_error(&self) -> bool` — true for 5xx status codes
- [ ] `Response::header(&self, name: &str) -> Option<&str>` — get a header value by name
- [ ] `Response::body(&self) -> &[u8]` — get the response body as bytes
- [ ] `Response::json<T: DeserializeOwned>(&self) -> Result<T, Error>` — deserialize body as JSON
- [ ] `Response::ensure_success(&self) -> Result<(), Error>` — returns `Error::HttpError` for non-2xx
- [ ] All response bodies are buffered into `Vec<u8>` (no streaming in Phase 1)
- [ ] `Response` is `Debug` (derive or impl)

## Non-Functional Requirements

- [ ] `Response::json()` returns `Error::Deserialization` on invalid JSON
- [ ] `Response::ensure_success()` includes status code and body in the error message
- [ ] `Response::header()` is case-insensitive per HTTP spec
- [ ] Body buffering has a reasonable maximum (e.g., 1MB) to prevent memory exhaustion
- [ ] `Response` does not implement `Clone` (body is consumed on first read) — or does implement it if body is cloned on first access
- [ ] No panics in any `Response` method

## Acceptance Criteria

1. `response.status()` returns the correct HTTP status code
2. `response.is_success()` is true for 2xx, false otherwise
3. `response.is_client_error()` is true for 4xx
4. `response.is_server_error()` is true for 5xx
5. `response.header("Content-Type")` returns the value or None
6. `response.body()` returns the raw response bytes
7. `response.json::<MyStruct>()` deserializes valid JSON correctly
8. `response.json::<MyStruct>()` returns `Error::Deserialization` for invalid JSON
9. `response.ensure_success()` returns `Ok(())` for 2xx
10. `response.ensure_success()` returns `Error::HttpError` for non-2xx with status and body

## Tests

### Unit Tests
```rust
#[test]
fn test_status_codes() {
    // Test with constructed Response
    let response = Response {
        status: StatusCode::OK,
        headers: HeaderMap::new(),
        body: b"{}".to_vec(),
    };
    assert!(response.is_success());
    assert!(!response.is_client_error());
    assert!(!response.is_server_error());
}

#[test]
fn test_status_4xx() {
    let response = Response {
        status: StatusCode::NOT_FOUND,
        headers: HeaderMap::new(),
        body: b"Not Found".to_vec(),
    };
    assert!(!response.is_success());
    assert!(response.is_client_error());
}

#[test]
fn test_status_5xx() {
    let response = Response {
        status: StatusCode::INTERNAL_SERVER_ERROR,
        headers: HeaderMap::new(),
        body: b"Server Error".to_vec(),
    };
    assert!(response.is_server_error());
}

#[test]
fn test_header_case_insensitive() {
    let mut headers = HeaderMap::new();
    headers.insert("Content-Type", HeaderValue::from_static("application/json"));
    // Test case-insensitive lookup
}

#[test]
fn test_json_deserialization() {
    let response = Response {
        status: StatusCode::OK,
        headers: HeaderMap::new(),
        body: b"{\"key\": \"value\"}".to_vec(),
    };
    let result: serde_json::Map<String, serde_json::Value> = response.json().unwrap();
    assert_eq!(result.get("key").unwrap().as_str().unwrap(), "value");
}

#[test]
fn test_json_deserialization_error() {
    let response = Response {
        status: StatusCode::OK,
        headers: HeaderMap::new(),
        body: b"not json".to_vec(),
    };
    let result: Result<serde_json::Value, _> = response.json();
    assert!(result.is_err());
}

#[test]
fn test_ensure_success_ok() {
    let response = Response {
        status: StatusCode::OK,
        headers: HeaderMap::new(),
        body: b"OK".to_vec(),
    };
    assert!(response.ensure_success().is_ok());
}

#[test]
fn test_ensure_success_error() {
    let response = Response {
        status: StatusCode::INTERNAL_SERVER_ERROR,
        headers: HeaderMap::new(),
        body: b"500".to_vec(),
    };
    let err = response.ensure_success().unwrap_err();
    match err {
        Error::HttpError { status, body, .. } => {
            assert_eq!(status, StatusCode::INTERNAL_SERVER_ERROR);
            assert_eq!(body, "500");
        }
        _ => panic!("expected HttpError variant"),
    }
}
```

## Notes

- Body buffering is configurable — the default should be reasonable for typical API responses
- `Response::header()` should be case-insensitive — HTTP headers are case-insensitive per RFC 7230
- Consider: should `Response` implement `Clone`? Body is already in `Vec<u8>`, so cloning is cheap. This enables multiple reads of the same response.
