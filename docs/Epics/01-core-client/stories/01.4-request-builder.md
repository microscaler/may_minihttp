# Story 01.4: RequestBuilder — GET/POST with Headers

## Description

Implement the `RequestBuilder` struct with fluent API for constructing HTTP requests. Supports GET and POST methods, custom headers, JSON body serialization, and raw byte body. The builder pattern allows chaining method calls before calling `.send()`.

## Functional Requirements

- [ ] `RequestBuilder` struct with fields:
  - `method: Method` (from `http 0.2`)
  - `path: String`
  - `headers: HeaderMap`
  - `body: Option<Vec<u8>>`
  - `content_length: Option<usize>`
- [ ] `RequestBuilder::header(key: &str, value: &str) -> Self` — add a custom header
- [ ] `RequestBuilder::json_body<T: Serialize + ?Sized>(body: &T) -> Self` — serialize to JSON and set Content-Type
- [ ] `RequestBuilder::raw_body(body: &[u8], content_type: Option<&str>) -> Self` — set raw byte body
- [ ] `RequestBuilder::send(self, client: &HttpClient) -> Result<Response, Error>` — execute the request
- [ ] GET requests have no body (ignore any body set via `raw_body()` or `json_body()`)
- [ ] POST requests include the body (Content-Length header set automatically)
- [ ] Default headers from `HttpClient` are merged into request headers (request-specific headers take precedence)
- [ ] `RequestBuilder::send()` constructs the raw HTTP request, writes to the shared connection, and returns the response
- [ ] `send()` uses `may_http::client::Request` internally for header/body setting

## Non-Functional Requirements

- [ ] No allocations in the hot path (builder pattern is consumed by `send()`, not cloned)
- [ ] JSON body is serialized synchronously (blocking)
- [ ] `RequestBuilder` is `Send` (required for passing between coroutines)
- [ ] `send()` does not panic — returns `Error` on any failure
- [ ] Header names are validated (ASCII only per HTTP spec)
- [ ] Content-Type defaults to `application/octet-stream` when not specified

## Acceptance Criteria

1. `client.get("/path").send()` returns a response without body
2. `client.post("/path").header("X-Custom", "value").send()` includes custom header
3. `client.post("/path").json_body(&obj).send()` serializes object to JSON with Content-Type header
4. `client.post("/path").raw_body(b"data", Some("text/plain")).send()` sends raw bytes
5. Multiple `.header()` calls accumulate headers
6. Request-specific headers override default headers from `HttpClient`
7. `send()` returns `Error::HttpError` for non-2xx status codes
8. GET requests ignore body (no Content-Length header sent)

## Tests

### Unit Tests
```rust
#[test]
fn test_get_no_body() {
    // GET should not include Content-Length or body
    let builder = HttpClient::connect("127.0.0.1", 8080)
        .unwrap()
        .get("/path")
        .json_body(&serde_json::json!({"key": "value"}));
    // Verify body is not set (or ignored) for GET
}

#[test]
fn test_header_chain() {
    let builder = HttpClient::connect("127.0.0.1", 8080)
        .unwrap()
        .post("/path")
        .header("X-A", "a")
        .header("X-B", "b")
        .header("X-C", "c");
    // Verify all three headers are set
}

#[test]
fn test_json_body_serializes() {
    let obj = serde_json::json!({"key": "value"});
    let builder = HttpClient::connect("127.0.0.1", 8080)
        .unwrap()
        .post("/path")
        .json_body(&obj);
    // Verify body contains JSON and Content-Type is set
}

#[test]
fn test_default_headers_overridden() {
    let client = HttpClient::connect("127.0.0.1", 8080)
        .unwrap()
        .with_default_headers({
            let mut h = HeaderMap::new();
            h.insert("X-Custom", HeaderValue::from_static("default"));
            h
        });
    let builder = client.post("/path")
        .header("X-Custom", "override");
    // Verify request-specific header overrides default
}
```

## Notes

- The `may_http::client::Request` type is the low-level bridge — we set method, URI, headers, and body on it, then `drop(req)` to send
- `may_http::client::Request` implements `Drop` which writes the request head and flushes the body — this is how the request is actually sent
- JSON serialization is synchronous (`serde_json::to_vec`)
